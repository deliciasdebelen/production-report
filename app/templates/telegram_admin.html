⚠️ Configuración de Bot Telegram

ℹ️ ¿Cómo obtener el Chat ID?

  1. Abre Telegram y busca @userinfobot
  2. Escríbele /start
  3. Te responderá con tu Chat ID numérico
  4. Usa ese número en el campo "Chat ID / Número"
